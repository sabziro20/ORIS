# Task Manager 2.0 (PyQt6)

Desktop-приложение для создания, редактирования и удаления задач. Задачи хранятся в `tasks.json`.

## Запуск

```
pip install PyQt6
python main.py
```

## Реализованные пункты: ABC

| Пункт | Что сделано |
|---|---|
| A | Приоритет выбирается через `QComboBox` и показывается рядом с названием задачи в списке |
| B | Кнопка **Delete** удаляет выбранную задачу после подтверждения через `QMessageBox` |
| C | Меню «О программе» открывает отдельный `QDialog` |

Дополнительно: задачи хранятся в `tasks.json` при запуске читаются оттуда; есть редактирование задач. Файл обновляется при добавлении, изменении и удалении.

## Файлы

- `main.py` — окно приложения, чтение и запись json
- `tasks.json` — список задач (хранилище задач)

## Как пользоваться

1. Заполните поля и нажмите **Create task** — задача появится в списке.
2. **Edit** — загрузить выбранную задачу в форму, изменить и нажать **Save changes**.
3. **Delete** — удалить выбранную задачу после подтверждения.
